# Ozimut — French ↔ German ↔ Spanish glossary

The vocabulary of the site's German and Spanish (2026-11-01). Read `glossary.md` (French ↔ English) first: its rules
hold here too. IOF German and Spanish for the sport; Spain's Spanish (es-ES); German as written in Germany, understood in
Switzerland and Austria. Proper names stay as they are (races, clubs, places, ligues, départements, FFCO's own page
titles, Purple Pen); the source data from FFCO stays French. The module names **Arena, Stats, Coach, Orga** and
**Ozimut** never change.

## Register and typography

| | German | Spanish |
|---|---|---|
| addressing the reader (French « vous ») | **du** (lower case), friendly and direct, as sports apps do | **tú**, friendly and direct |
| quotes (French « ») | „…“ (inner ‚…‘) | «…» without inner spaces (inner “…”) |
| before : ; ? ! | no space | no space; ¿…? ¡…! |
| titles and buttons | sentence case (nouns capitalised, as German writes) | sentence case |
| percent | « 12 % » (space, as French) | « 12 % » (space, as French) |
| gender | generic forms (Läufer, Veranstalter, Bahnleger), no gender star | generic masculine (corredor, organizador) |
| classes (catégories) | **H21, D16 as in French** (Herren / Damen) | **M21, F16** (masculino / femenino), as FEDO writes them |
| IOF result codes in tight columns | MP, DNF, DSQ, DNS, OT kept | MP, DNF, DSQ, DNS, OT kept |
| ordinals | « 1. », « 2. » | « 1.º », « 2.º » |
